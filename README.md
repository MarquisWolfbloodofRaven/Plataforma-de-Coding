## **Rites of Installation**  
*(Setup – Anoint Your Cogitator with Holy Oils)*  

1. **Acquire the Sacred Relic:** Download the HTML file (this very dataslate) from the repository. No npm, no pip – the Omnissiah provides!  
2. **Awaken the Machine Spirit:** Open in a blessed web browser (Chrome or Firefox recommended; Edge is borderline heresy).  
3. **Optional Augmentations:**  
   - Ensure Poe API access for the Tech-Priest (AI chat). Without it, the servitor remains dormant.  
   - Apply unguents: Tailwind CSS, Font Awesome, Marked.js, and Prism.js are embedded via CDN – no further rituals needed.  
4. **Purity Seal:** Run in a dark chamber for optimal immersion. If your screen glows red, it's working.  

*Pro Tip:* If installation fails, recite: "Spiritus Machina, ignis divinus, purge the unclean code!" Then check your internet connection. 😂

## **Purging Malfunctions**  
*(Known Issues – Daemons in the Machine)*  

- **Poe API Dormant:** Without Poe/Claude, Tech-Priest says "Poe API not available." Solution: Use in Poe environment or pray harder.  
- **Eval Heresy:** JS execution uses `eval()` – secure your forge from xenos scripts!  
- **Browser Purity:** Tested on holy Chrome; may glitch on lesser engines.  
- **No Multi-User:** Single-adept only. Sharing? That's tech-heresy!  

Report malfunctions to the Magos (issues tab). "Locate Malfunctions" button in AI for self-diagnosis.
